AGA-Schlaftrainer Pro V3

Dateien fuer GitHub Pages: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
Alle Dateien zusammen ins Hauptverzeichnis (root) des Repositorys hochladen. index.html muss direkt im Hauptverzeichnis liegen.

Neue Funktionen: adaptiver Rhythmusplan, einstellbare Startzeiten, 1-Minuten-Atemübung, bestehender Schlaftracker, Wochenübersicht, Checkliste, Erinnerungen und JSON-Backup.

Datenschutz: Eintraege werden lokal im Browser gespeichert. Backup regelmaessig exportieren, wenn du die Daten behalten willst. Erinnerungen koennen bei geschlossener iPhone-Web-App eingeschraenkt sein; Kalender-Import ist die zuverlässigere Alternative.
